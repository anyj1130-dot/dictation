anyj1130-dot.github.io/dictation/
② 내 시트 (우리 반 기록)우리 반 학급·학생·점수가 쌓여요. 배포해서 씁니다.
③ 원본 시트 (빈 틀)다른 선생님이 복사해 가는 시트. 학급도 기록도 없는 빈 틀. 배포하지 않아요.

학생은 …/dictation/?s=서버ID 링크(또는 QR)로 들어와요. 링크 끝의 ?s=가 “어느 선생님 시트에 기록할지”를 알려 줘요. 한 번 들어오면 태블릿이 기억해요.

1GitHub에 화면 올리기

이미 올려 두셨으면 목록만 확인하세요

저장소 anyj1130-dot/dictation의 맨 바깥이 이렇게 되어 있어야 해요.

audio/   css/   data/   js/
config.js   index.html   start.html   teacher.html   README.md

config.js — 두 줄

const API_URL = "내 시트의 웹 앱 URL";            // 없어도 됨 (링크의 ?s= 가 우선)
const TEMPLATE_URL = "원본 시트의 /copy 주소";     // 3단계에서 채워요
파일을 고쳐 올릴 때는 같은 이름 그대로 덮어써요. 다운로드 폴더에 같은 파일이 있으면 index (1).html처럼 이름이 바뀌니 조심하세요. 앱은 열 때마다 최신 파일을 받아 오니, 올린 뒤 1~2분이면 반영돼요.
저장소는 Public이어야 해요. 무료 계정에서 Private으로 바꾸면 사이트가 꺼져요. 학생 기록은 GitHub가 아니라 구글 시트에 있어요.

2내 시트 (우리 반 기록용)

약 10분 · 개인 Gmail 계정으로

  1. 지금 쓰는 받아쓰기 기록 시트 (없으면 새 스프레드시트) → 확장 프로그램 → Apps Script → 내용을 모두 지우고 Code.gs를 통째로 붙여 넣기 → 💾 저장
  2. 위쪽 함수 목록에서 setup → ▶ 실행 (처음이면 권한 승인)
  3. 시트로 돌아와 설정 탭 B3에 https://anyj1130-dot.github.io/dictation/ (주소 확인: -dot 빠지지 않게)
  4. 배포
    • 처음이면: 배포 → 새 배포 → 톱니 웹 앱 → 실행 나 / 액세스 권한 모든 사용자 → 배포
    • 이미 배포한 적 있으면: 배포 → 배포 관리 → 연필 ✏️ → 버전 새 버전 → 액세스 권한 모든 사용자 확인 → 배포 (주소가 그대로 유지돼요)
  5. 마지막 화면의 웹 앱 URL 옆 [복사] 버튼으로 복사 (드래그하면 잘리기 쉬워요)
  6. 시트 새로고침 → 맨 위 메뉴줄 맨 오른쪽의 받아쓰기 메뉴
    • 처음이면 ① 우리 반 시작하기 → 주소 붙여 넣기 → 학급 이름·교사 비밀번호 → 학생 주소·QR 완성 (Apps Script에 다녀와서 안내창이 닫혀 있으면 ① 우리 반 시작하기를 한 번 더 누르면 주소 칸이 다시 나와요)
    • 예전에 주소를 넣었으면 웹 앱 주소 다시 넣기 → 새로 복사한 주소
  7. 받아쓰기 → 연결 상태 확인하기에서 “✅ 웹 앱이 잘 열려요”가 나오면 끝!
⚠️ 액세스 권한은 꼭 ‘모든 사용자’. ‘Google 계정이 있는 모든 사용자’나 ‘나만’이면 학생 화면에서 “선생님 서버에 연결하지 못했어요”가 나와요. 주소를 저장할 때 앱이 직접 열어 보고 잘못되면 알려 줘요.

그다음

  • 교사 화면(…/dictation/teacher.html?s=…) → 학생 관리에서 번호, 닉네임, 비밀번호를 한 줄에 한 명씩 붙여 넣어 등록
  • 교사 화면 설정·QR 탭 → QR 크게 보기를 칠판에 띄우기
  • 학생: QR로 들어와 학급 → 닉네임 → 비밀번호. 다음부터는 바로 들어가요.

3원본 시트 (다른 선생님이 복사해 갈 빈 틀)

약 5분 · 한 번만

  1. 구글 드라이브 → 새 스프레드시트 → 이름 받아쓰기(원본)
  2. 확장 프로그램 → Apps Script → Code.gs 붙여 넣기 → 💾 → setup 실행
  3. 설정 탭 B3에 https://anyj1130-dot.github.io/dictation/ (B1은 비워 두기)
  4. 공유 → 일반 액세스 링크가 있는 모든 사용자 · 뷰어 → 링크 복사
  5. 주소 끝 /edit…를 지우고 /copy로 바꾸기
    예: https://docs.google.com/spreadsheets/d/1AbC…xyz/copy
  6. GitHub config.js의 TEMPLATE_URL 따옴표 안에 넣고 Commit
⚠️ 원본 시트에서는 배포도, 메뉴 [① 우리 반 시작하기]도 하지 마세요. 학급이나 학생을 만들면 그 내용이 다른 선생님 사본에 그대로 복사돼요. 혹시 원본에서 학급을 만들었다면, 그 시트는 ‘내 시트’로 쓰고 원본은 새로 만들어 주세요.

4다른 선생님께 나눠 주기

이 주소 하나만 알려 주세요.

https://anyj1130-dot.github.io/dictation/start.html

다른 선생님은 사본 만들기 → 배포 한 번 → 메뉴 [① 우리 반 시작하기]만 하면 자기 반 QR이 나와요 (약 5분). GitHub는 필요 없어요.

다른 선생님도 개인 Gmail로 해야 해요. 학교(워크스페이스) 계정은 ‘모든 사용자’ 배포가 막혀 있는 경우가 많아요.

5음성 파일 (이미 만들었으면 건너뛰기)

  1. 앱 폴더의 MAKE_AUDIO.bat 더블클릭 (Python 필요 — 설치할 때 “Add python.exe to PATH” 체크)
  2. 끝나면 열리는 audio 폴더의 .js 파일 16개를 GitHub audio 폴더에 올리기
  3. 학교 인터넷에서 막히면 휴대폰 핫스팟이나 집 인터넷으로 실행

음성은 GitHub에 있어서 모든 선생님이 같이 써요. 한 번만 만들면 돼요.
