받아쓰기

우리 반 받아쓰기 시작하기

약 5분 · 컴퓨터에서 · 개인 Gmail 계정으로 해 주세요 (학교 계정은 막혀 있을 수 있어요)

1

내 구글 드라이브에 받아쓰기 시트 복사하기

버튼을 누르고 사본 만들기를 누르면 끝이에요. 학생 기록은 이 시트에 저장되고, 선생님만 볼 수 있어요.

📄 사본 만들기
아직 원본 시트 주소가 등록되지 않았어요. 앱을 나눠 준 선생님께 알려 주세요.
2

배포 한 번 하기 (처음 한 번만)

  1. 복사된 시트를 열면 위쪽 메뉴줄(파일 수정 보기 … 도움말) 맨 오른쪽에 받아쓰기 메뉴가 새로 생겨요. 시트를 열고 5~10초 기다리면 나타나요. (안 보이면 새로고침) → 받아쓰기 → ① 우리 반 시작하기
  2. ‘승인 필요’ 창이 뜨면 계속 → 내 계정 선택 → 허용
  3. 나오는 안내대로: 확장 프로그램 → Apps Script → 배포 → 새 배포 → 톱니바퀴 웹 앱
  4. 실행: 나 / 액세스 권한: 모든 사용자 → 배포 → 액세스 승인
  5. 웹 앱 URL 옆 복사 → 시트 창으로 돌아와 칸에 붙여 넣고 저장하고 다음으로
⚠️ “Google에서 확인하지 않은 앱” 화면이 나와요. 선생님 본인이 복사한 시트라서 뜨는 안내예요. 고급 → (안전하지 않음)으로 이동 → 허용을 누르면 돼요. 이 시트는 선생님 시트에 받아쓰기 기록을 쓰는 일만 해요.
3

학급 만들고 QR 받기

  1. 학급 이름과 교사 비밀번호를 넣으면 학생 접속 주소와 QR 코드가 바로 나와요.
  2. 교사 화면 열기 → 학생 관리에서 번호, 닉네임, 비밀번호를 붙여 넣어 학생을 등록해요.
  3. QR 코드를 칠판에 띄우면, 학생들은 태블릿으로 찍고 학급·닉네임·비밀번호로 들어와요. 한 번 들어오면 태블릿이 기억해요.

QR은 교사 화면 설정·QR 탭이나 시트 메뉴 받아쓰기 ▸ ① 우리 반 시작하기에서 언제든 다시 볼 수 있어요.

학생 태블릿 준비

삼성 키보드는 설정 → 일반 → 삼성 키보드 설정에서 예측 텍스트와 자동 맞춤법 검사를 꺼 주세요. 켜져 있으면 틀리게 써도 키보드가 고쳐 버려요.
